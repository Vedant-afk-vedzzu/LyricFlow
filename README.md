# LyricFlow

A desktop music overlay concept built with Electron, React, TypeScript, and Vite.

LyricFlow is designed to sit over your desktop with a clean, transparent interface. The current interface prototype includes a vinyl-style visual, song information, a lyrics panel, and a spectrum-style visualizer.

## Current features

- Frameless, transparent Electron overlay window
- Vinyl-inspired music visual
- Song title, artist, and album information using sample data
- Lyrics panel placeholder
- Static spectrum visualization prototype
- React + TypeScript renderer powered by Vite

## Project status

This is an in-progress prototype. Spotify integration, synchronized lyrics, and a live audio-frequency visualizer should be considered planned work unless implemented in the current code.

## Tech stack

- Electron
- React
- TypeScript
- Vite
- CSS

## Run locally

Requirements: Node.js and npm.

1. Clone the repository:
   ```bash
   git clone https://github.com/Vedant-afk-vedzzu/LyricFlow.git
   ```
2. Enter the project folder:
   ```bash
   cd LyricFlow/lyricflow
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

Check `package.json` for the available scripts and build command.
